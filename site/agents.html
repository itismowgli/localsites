AI agentsAn MCP server that asks before risky steps

Your agent runs your stack, and asks first

LocalSites is an MCP server. Claude, Cursor, VS Code and Windsurf connect in one click, and anything risky waits for you in the app.

Download for macOSLinux (beta)

Free · MIT licence · Apple silicon and Linux · No account, no telemetry

Tools

Typed tools instead of shell commands

Agents list projects, switch PHP, read logs, run checks and manage databases through tools that say what they do and whether they need you.

  • Honest labelsEach tool says if it only reads, changes something or needs approval.
  • No surprise argumentsUnknown parameters are refused.
  • Built-in instructionsAgents are told never to change databases unless you asked.
Approvals

Risky steps wait for your click

The card shows the exact tool and its parameters, and what’s at stake in plain words. Steps that can’t be undone need the button held for a moment.

  • Only you can answerAgents never get the approve tool.
  • Nothing happens on silenceNo answer in 90 seconds means no change.
  • Answer from anywhereThe card, the notification, the bell or the run list.
Passes

Approve once, for ten minutes

For everyday actions you’re watching, approve the same step on the same project for ten minutes. The pass counts down, and you can end it early.

  • Narrow on purposeSame action, same agent, same project.
  • Some steps always askDeleting, installing and publishing never get a pass.
  • Shown in the status barWith the time left.
Runs

Every run, every call

Each agent session is a run with a live clock, its status and its last steps. Open one to see every tool it called, with Undo where the change can be undone.

  • Undo with careOnly when nothing has changed it since.
  • Backups for the restDatabase steps link straight to their backups.
  • Approve from the runWhen it’s waiting on you.
Secrets

Secrets stay with you

Agents see the names of your .env settings, never the values. Tools that reveal passwords stay off unless you start the server with --allow-secrets.

  • Masked in requestsApproval cards show passwords as dots.
  • Config backed upConnecting an agent copies its settings file first.
  • Names cleanedAn agent’s name is shortened and stripped of control characters.

FAQ

Questions, answered

Which agents work with LocalSites?

Claude Desktop, Claude Code, Cursor, VS Code and Windsurf connect in one click. Zed and any other MCP client work with a few lines of settings.

Can an agent approve its own request?

No. The approve tool is never offered to agents, and requests can only be answered from the app.

What does an agent see of my passwords?

Nothing by default. It sees setting names, not values, and tools that reveal passwords stay off unless you add --allow-secrets.
