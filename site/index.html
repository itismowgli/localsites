Only in LocalSites

Things you won’t find in other local servers

We compared MAMP PRO, Laravel Herd, Valet, Local, XAMPP, DDEV, Lando, ServBay and FlyEnv in November 2026. None of them does these.

  • Agents wait for your clickA risky agent action shows the exact request and waits for Approve in the app. The agent can’t answer it.
  • Secrets stay with youAgents see your .env setting names, never the values. Tools that reveal passwords are off unless you turn them on.
  • A backup before every risky stepImport, restore, empty and delete back up first. If the backup fails, nothing is changed.
  • A data browser that can’t hurt youThe database server refuses changes until you allow them. Edits show their SQL and save all at once, or not at all.
  • Moves from MAMP, checkedDatabases from MAMP PRO, MAMP and XAMPP are copied and compared row by row. The originals are only read.
  • Shares that close themselvesA password by default, limited guesses, a time limit, and .env and .git never served.
  • A certificate that can’t fake the webThe certificate authority LocalSites makes can only sign .test and localhost addresses.
  • Updates you can take backEvery update is signed and has to start before it replaces the app. The old version stays one click away.

FAQ

Questions, answered

Is LocalSites a free alternative to MAMP PRO, Laravel Herd or XAMPP?

Yes. LocalSites is free and open source under the MIT licence, with no paid tier. It does the same core job: an HTTPS .test address for every project, PHP per project and MySQL. It can copy your databases from MAMP PRO, MAMP or XAMPP and check every row, and works alongside Laravel Valet.

How do I run several PHP versions on a Mac?

Install the versions you want with Homebrew (for example php@8.2 and php), then pick the version for each project in LocalSites. Each project gets its own PHP-FPM pool, and Laravel projects use the version their composer.json asks for.

Does LocalSites work with Laravel Valet?

Yes. If Valet is installed, LocalSites uses Valet's domains and certificates and shows Valet sites as served by Valet. Without Valet it runs its own HTTPS proxy and DNS for .test domains.

Can AI coding agents use LocalSites?

Yes. LocalSites is an MCP server. Claude Desktop, Claude Code, Cursor, VS Code and Devin Desktop connect in one click. Read-only tools run freely; risky actions wait for you to approve them in the app.

What do I need to install first?

Nothing. On first launch LocalSites offers to install Homebrew, then Apache, MySQL 8.4 and every PHP version your projects use, showing each command first. You can add more PHP versions later.

How do I get HTTPS .test domains for local sites on a Mac?

Put a project folder in ~/Sites/localhost (or any folder you add) and switch it on in LocalSites. It is served at https://<folder>.test with a trusted certificate and no port number. LocalSites uses Laravel Valet's domains if you have Valet, or its own proxy and DNS otherwise.

How do I connect Claude Code, Cursor or VS Code to my local sites?

Open Settings → AI agents and click Connect next to your client, or run localsites mcp config. For Claude Code: claude mcp add localsites -- "$(which localsites)" mcp. The agent can then list projects, switch PHP versions, read logs and run health checks.

macOS says it can't verify LocalSites. What do I do?

LocalSites isn't notarized by Apple yet, because that needs a paid developer account. The code is open source. To open it the first time: click Done on the warning, open System Settings → Privacy & Security, scroll to Security and click Open Anyway next to LocalSites, then confirm. You only need to do this once.

Does LocalSites run on Windows or Linux?

Linux, yes, as a beta from version 1.4: Ubuntu 24.04 and newer, Debian 12 and newer, and Fedora, on x86_64 and arm64. Download the .deb or .rpm from the latest release; LocalSites installs Homebrew, PHP, Apache and MySQL for you, like on a Mac. Windows is planned.
