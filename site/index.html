Everything a local PHP and web stack needs

One small native app, about 22 MB, that stays quiet in the background.

HTTPS for every folder

Drop a folder in your projects folder and open https://folder.test. No port numbers. Uses Laravel Valet if you have it, or its own proxy and DNS.

PHP 7.4 to 8.5 per project

Switch in one click. Each project gets its own PHP-FPM pool, and Laravel uses the version its composer.json asks for. Xdebug per project.

Apache or Nginx

Full .htaccess support on Apache, or Nginx with pretty-URL fallback. Laravel, WordPress, plain PHP and static sites are detected automatically.

Node, Next.js, Docker, anything

Runs your dev server behind https://name.test with npm, pnpm, yarn or bun, and restarts it if it crashes. Or any command, such as Django or Rails.

MySQL with one login per project

MySQL 8.4 LTS, no shared root, passwords in the macOS Keychain. Export, import, backups and restore. MySQL sleeps when nothing needs it.

Add-ons when you need them

Mailpit, Valkey and Redis, Memcached, PostgreSQL, Meilisearch and MinIO, with connection settings ready to paste.

A data browser that's safe by default

Browse LocalSites MySQL, MAMP's MySQL, any MySQL or MariaDB over SSH, PostgreSQL and SQLite.

  • Read-only first. Every connection starts read-only
  • Review before saving. Edits are staged and you see the exact SQL
  • One transaction. All of it saves together, or nothing does
  • Open in TablePlus, Sequel Ace or Adminer with the details filled in

Coming from MAMP PRO

LocalSites is free and open source. Moving over keeps your data safe.

  • Copy your databases from MAMP PRO, MAMP or XAMPP in one step. The source is only read, and every table is checked row by row
  • Browse MAMP's MySQL directly while you move over
  • Connect a project to its copied database in one click. Your .env is backed up first
  • Keep Valet sites where they are, or move one over in one click
localsites import database mamp-pro shop_db   # copy and verify; the original is untouched

Built for you and your AI agent

LocalSites is an MCP server. Claude Desktop, Claude Code, Cursor, VS Code and Windsurf connect in one click.

  • Typed tools: list projects, switch PHP, read logs, run health checks
  • Risky actions wait for you. Approve them in the app; agents can't approve themselves
  • Passwords stay hidden unless you turn that on

Git, sharing and a Doctor

  • Git built in: branches, changes, history, and the GitHub pull request and CI status for your branch
  • Share a site through a free Cloudflare tunnel, with a password and a time limit
  • Doctor checks runtimes, ports, domains and certificates, with a fix for each problem
  • Keyboard-first: ⌘K command palette, tabs, light and dark themes, a menu bar icon

Install

Download the app from the latest release. It uses PHP, Apache and MySQL from Homebrew:

brew install httpd mysql@8.4 php        # plus any php@X.Y versions you want

Open LocalSites, switch a project on and open https://folder.test.

Questions

Is LocalSites a free alternative to MAMP PRO?

Yes. LocalSites is free and open source under the MIT licence. It gives every project an HTTPS .test address, PHP per project and MySQL, and can copy your databases from MAMP PRO, MAMP or XAMPP and check every row.

How do I run several PHP versions on a Mac?

Install the versions you want with Homebrew (for example php@8.2 and php), then pick the version for each project in LocalSites. Each project gets its own PHP-FPM pool, and Laravel projects use the version their composer.json asks for.

Does LocalSites work with Laravel Valet?

Yes. If Valet is installed, LocalSites uses Valet's domains and certificates and shows Valet sites as served by Valet. Without Valet it runs its own HTTPS proxy and DNS for .test domains.

Can AI coding agents use LocalSites?

Yes. LocalSites is an MCP server. Claude Desktop, Claude Code, Cursor, VS Code and Windsurf connect in one click. Read-only tools run freely; risky actions wait for you to approve them in the app.

Does LocalSites run on Windows or Linux?

Not yet. LocalSites is macOS only for now. Windows and Linux versions are planned.
