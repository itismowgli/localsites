FAQ

Questions

Is LocalSites a free alternative to MAMP PRO?

Yes. LocalSites is free and open source under the MIT licence. It gives every project an HTTPS .test address, PHP per project and MySQL, and can copy your databases from MAMP PRO, MAMP or XAMPP and check every row.

How do I run several PHP versions on a Mac?

Install the versions you want with Homebrew (for example php@8.2 and php), then pick the version for each project in LocalSites. Each project gets its own PHP-FPM pool, and Laravel projects use the version their composer.json asks for.

Does LocalSites work with Laravel Valet?

Yes. If Valet is installed, LocalSites uses Valet's domains and certificates and shows Valet sites as served by Valet. Without Valet it runs its own HTTPS proxy and DNS for .test domains.

Can AI coding agents use LocalSites?

Yes. LocalSites is an MCP server. Claude Desktop, Claude Code, Cursor, VS Code and Windsurf connect in one click. Read-only tools run freely; risky actions wait for you to approve them in the app.

What do I need to install first?

Homebrew, then brew install httpd mysql@8.4 php, plus any other php@X.Y versions you want. LocalSites uses them directly.

Does LocalSites run on Windows or Linux?

Not yet. LocalSites is macOS only for now. Windows and Linux versions are planned.
