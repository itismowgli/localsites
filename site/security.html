In detail

Every safeguard, by area

Each one is in the code today. The source is open if you want to check.

Agents and approvals

  • Owner-only controlThe app, CLI and agents talk over a socket only your account can open, with a token that changes every start.
  • Person-only actionsInstalling updates, moving projects to the Trash and installing Homebrew are refused for agents and scripts.
  • Risky fields need approvalChanging a start command, environment variables or the projects folder waits for you.
  • Secrets maskedPasswords, tokens and every environment value show as dots in requests and the activity log.
  • Hidden toolsApproval tools are never offered to agents; password tools need --allow-secrets.
  • A record of everythingEvery change and every agent call is logged, without secrets, in an owner-only file.

Your data

  • Read-only transactionsBrowsing and queries run in a transaction the database server enforces as read-only.
  • Write statements blockedIn read-only mode only SELECT, SHOW, DESCRIBE, EXPLAIN and WITH can run.
  • All or nothingStaged edits save in one transaction, only if each row still matches.
  • Values always boundFilters and edits pass values as parameters; column names are checked.
  • .env backed up firstKept outside the project, because it holds passwords. One click puts it back.
  • Git that can’t lose workPull is fast-forward only, and project hooks never run.

Secrets

  • KeychainThe macOS Keychain, or the Secret Service on Linux.
  • Never on a command linePasswords reach MySQL tools through a pipe, never the process list.
  • One login per databaseEach database’s user can reach only that database.
  • Certificate limited to .testThe certificate authority can only sign .test and localhost.
  • MySQL locked downListens on 127.0.0.1, with remote protocols and local file loading off.
  • Strong passwordsMade with the system’s secure random source.

Sharing

  • Password by defaultAt least 8 characters; bore always needs one.
  • Limited guesses10 wrong passwords per visitor in 10 minutes, 100 overall.
  • Local-only pages stay closedA visitor is never seen as localhost by your site.
  • One site per shareEach share reaches one site, never your other sites or databases.
  • Your ssh identity privatetunnl.gg runs without your keys, agent or config.
  • Ends by itselfNo longer than 24 hours, extensions included.

Updates and installs

  • Signed releasesNothing installs unless the release signature matches the key in the app.
  • Checked downloadsSize and SHA-256 must match, or the download is deleted.
  • A failed swap undoes itselfIf any step fails, the old app is put back.
  • Homebrew checked by AppleThe installer must pass Apple’s check, or it’s deleted.
  • Adminer pinnedA fixed release, refused unless its fingerprint matches.
  • Signed Linux repositoryPackages and repository metadata are signed.

Privacy

  • No telemetryNo accounts, no tracking, no upsells.
  • Problem reports offTurn them on if you like; each report is cleaned and shown to you first.
  • Analytics offHomebrew and Meilisearch run with analytics switched off.
  • Only your computerEvery service listens on 127.0.0.1.
  • Strict app securityOnly the app’s own code runs in its window.
  • TestedDedicated security tests cover the API, agents, sharing and certificates.
Limits

Where the protection stops

So you know exactly what it covers, and what it doesn’t.

  • Strongest check on signed macOS buildsProving the caller by code signature works only there. On Linux and development builds the caller’s own name decides.
  • Approvals guard against agents, not malwareAnything already running as you can read what you can. Approvals stop an agent acting on its own, for example after a prompt injection.
  • bore shares are plain httpIts pages and password travel unencrypted; the app says so when you pick it.
  • Linux keyring sessionSecrets travel over your own session bus without extra encryption, as libsecret does by default.

FAQ

Questions, answered

Does LocalSites send any data anywhere?

No. There is no telemetry, no account and no tracking. Problem reports are off unless you turn them on, and each report is cleaned and shown to you first.

Can other devices on my network reach my sites?

No. Every service listens on 127.0.0.1, so only your computer can reach it. To show a site to someone else, share it with a password and an end time.

What if an AI agent is tricked by a prompt injection?

Risky steps still wait for your click, and the agent can’t approve its own request. Approvals stop an agent acting on its own; they don’t protect against malware already running as you.
