Projects and addresses

20

Drop a folder in, get a working https address.

  • Every folder is a projectEach folder in your projects folder shows up on its own, ready to switch on.
  • https://name.test for each oneA real address with a trusted certificate and no port number.
  • Several projects foldersAdd as many folders as you like, each with its own label.
  • Group folders understoodOne folder per git account? LocalSites looks one level down for the projects.
  • Type detected for youLaravel, WordPress, Next.js, Node, PHP and static sites, with their versions.
  • Change the type yourselfForce PHP, static, Next.js, Node, a custom command, Docker or not a website.
  • Unique addressesTwo folders called admin become admin.test and admin-group.test.
  • www works toowww.name.test opens the same site.
  • Missing packages flaggedA project without vendor or node_modules says so, with an Install button.
  • Install dependenciesRuns composer or npm, pnpm, yarn or bun in the background with a log.
  • Rename a projectThe folder is renamed; settings, logs and the address move with it.
  • Hide a projectIt stops being listed and served. Files and database stay as they are.
  • Move to the TrashYou type the name to confirm, and can put it back from the Trash.
  • FavoritesStar a project to pin it in the sidebar.
  • Open it in your appsBrowser, Finder or Files, your terminal and your code editor.
  • The Open button remembersThe way you last opened a project becomes the main button.
  • Your editor, never a guessThe first Open asks which editor you use and remembers it.
  • 40+ apps recognisedVS Code, Cursor, Zed, PhpStorm, Ghostty, Fork, TablePlus and more.
  • Project fileA localsites.yaml in the project sets its domain, PHP, web root and database.
  • Protected folders handledA projects folder in Documents waits for macOS access instead of freezing anything.

PHP and web servers

15

The right PHP and web server for each project.

  • PHP per projectEach project picks its own version, side by side.
  • PHP from composer.jsonLaravel projects get the newest installed version their composer.json allows.
  • Default for new projectsChoose the PHP version new projects start with.
  • Own PHP-FPM pool per projectIts own socket, temp folder and error log.
  • Unused versions stopA PHP version with no project running doesn't use memory.
  • MAMP-like php.ini defaultsUpload size, memory and buffering match MAMP, so moved sites behave the same.
  • php.ini overridesChange safe settings for all projects, or for one project on top.
  • Xdebug per projectSwitch it on for the project you're debugging, on port 9003.
  • Xdebug install helpShows the one pecl command when Xdebug isn't installed. Your php.ini isn't touched.
  • Extensions listSee every PHP version's extensions in Settings.
  • Broken PHP foundA PHP build that can't start is listed with the command that repairs it.
  • Apache or NginxPick per project. Apache reads .htaccess; Nginx falls back to index.php.
  • Web root detectedpublic/ and similar folders are found for you, or set your own.
  • Configs tested firstApache and PHP configs are checked before reloading, so a typo never takes sites down.
  • mail() goes to MailpitWhen Mailpit is on, PHP's mail() lands in its inbox.

Databases

19

MySQL 8.4, PostgreSQL and backups you don't have to think about.

  • MySQL 8.4 LTSSet up on first use, with a random root password in the Keychain.
  • One login per databaseEach database gets a user that can only reach that database.
  • See a project's databaseThe project panel shows which database it uses, from LocalSites, .env or wp-config.php.
  • Open it in one clickJump from a project straight to its database in the data browser.
  • MySQL sleeps when idleAfter 20 quiet minutes it stops, and wakes when something needs it.
  • Keep it running insteadSwitch idle sleep off in Settings.
  • MAMP-compatible settingssql_mode and table-name handling match MAMP, so moved sites behave the same.
  • Connection snippetsReady to paste for Laravel, Node, Django, Rails, WordPress, PDO and GUI apps.
  • Open in TablePlus or Sequel AceThe details are filled in for you.
  • Export.sql or .sql.gz, full, structure only or data only.
  • Import.sql, .sql.gz or .zip, with a backup made first.
  • BackupsMade before every import, restore, empty and delete. Restore one in a click.
  • DuplicateCopy structure and data into a new database with its own login.
  • Empty or deleteEach one backs up first, and you type the name to delete.
  • Connect a projectWrites the database's own login into .env, after backing the file up.
  • Undo connectPuts the project's .env back as it was.
  • PostgreSQL 17 add-onCreate, export, import, duplicate, empty and delete, all backed up first.
  • AdminerA checked copy of Adminer at adminer.test, if you prefer a web tool.
  • Change the root passwordRandom and strong by default, saved in the Keychain.

Data browser

18

Browse and edit tables without fear of breaking them.

  • Every kind of databaseLocalSites MySQL, MAMP's MySQL, MySQL or MariaDB over SSH, PostgreSQL and SQLite.
  • SSH tunnelsUse your own ssh keys. It never asks for passwords.
  • Read-only until you say soThe database server itself refuses changes until you allow them.
  • Edit modeChange cells, add rows and mark rows for deletion.
  • See the SQL firstReview & save shows the exact statements before anything is written.
  • All or nothingChanges save in one transaction, only if each row still matches.
  • Filter rules that read like a sentenceWhere, and, or, with groups inside groups.
  • Filters fit the columnDate pickers, ranges, lists and yes or no, depending on the column type.
  • Filter as SQL, JSON or plain EnglishThe output rewrites itself as you build the filter.
  • Undo filter changes⌘Z and ⇧⌘Z, one step per field.
  • Edit the filter as SQLSend the filter to the SQL tab with its values written in.
  • SQL tabRun a query with autocomplete for keywords, tables and columns.
  • Query historyThe last 60 queries for each connection.
  • Writes need two switchesThe connection must allow changes, and each write query must ask to.
  • Sort and pageClick a column to sort; 100 rows a page.
  • StructureColumns, types, keys and indexes for every table.
  • Export resultsCopy as CSV or save a CSV file.
  • Asks before throwing work awayUnsaved edits are never dropped without asking.

Safety and privacy

11

What it does with your computer, and what it won't do.

  • No telemetryNo accounts, no tracking, no upsells.
  • Certificate limited to .testThe certificate authority can only sign .test and localhost, never real websites.
  • Only your computerEvery service listens on 127.0.0.1.
  • Owner-only controlThe app, CLI and agents talk over a socket only your account can open.
  • The app proves who it isOn macOS, LocalSites checks the code signature of whoever is asking.
  • Passwords in the KeychainOr the Secret Service on Linux. Never on a command line.
  • Backups before anything riskyIf a backup fails, nothing is changed.
  • Problem reports are offTurn them on if you like; you see each report, cleaned, before it's sent.
  • Trash, not deleteProjects go to the Trash so you can put them back.
  • .env backups kept outsideThey hold passwords, so they never sit in a folder that's served or committed.
  • Strict app securityOnly the app's own code runs in its window.
