Switching

Bring what you already have

The originals stay where they are until you’re ready.

MAMP PRO and MAMP

Copy your databases in one step. The source is only read, and every table is checked row by row. Browse MAMP’s MySQL in the data browser while you move over.

XAMPP

The same one-step copy for XAMPP’s databases, verified table by table. Your XAMPP install isn’t changed.

Laravel Valet

LocalSites runs alongside Valet, uses its domains and certificates, and moves one site over in a click. Valet’s config is never edited.

Laravel Herd, DBngin or another MySQL

Export with the tool you use today, then import the .sql, .sql.gz or .zip file. Each project gets its own login.

Local and other WordPress setups

Add the site’s folder and import its database. WordPress is detected and its database shown in the project.

Docker, Next.js and Node

Keep your docker compose setup or dev server. LocalSites runs the command and serves it at https://name.test.

Not yet

What LocalSites doesn’t do yet

So you know before you switch. Some are on the way; the issue tracker has the plan.

  • WindowsPlanned. macOS and Linux (beta) today.
  • Apple notarizationThe first launch needs Open Anyway in System Settings.
  • More database enginesMySQL 8.4 and PostgreSQL 17 only. No MariaDB, MongoDB or second MySQL version.
  • Managed Python, Ruby or GoLocalSites runs your command; it doesn’t install those runtimes.
  • Testing from your phoneSites are reachable only from your computer. Share a link instead.
  • Push to hostingNo deploy or sync with hosting providers.
