Data browser

Read-only until you say so

The database server itself refuses changes until you allow them. When you edit, you see the exact SQL first, and it saves all at once or not at all.

Save 3 changes to orders?
UPDATE `orders` SET `status` = ? WHERE `id` = ?
UPDATE `orders` SET `total` = ? WHERE `id` = ?
DELETE FROM `orders` WHERE `id` = ?

These run in one transaction. If any row changed since you loaded it, nothing is saved.

FAQ

Questions, answered

Will LocalSites touch my MAMP databases?

No. It only reads them to make a copy, then checks the copy row by row. Projects keep using MAMP’s MySQL until you connect them to the copy.

Can I edit data safely?

Yes. Every connection opens read-only. In Edit mode your changes wait, show their exact SQL, and save in one transaction only if each row still matches.

Which databases can I browse?

LocalSites MySQL, MAMP’s MySQL, any MySQL or MariaDB (also over SSH), PostgreSQL and SQLite files.
