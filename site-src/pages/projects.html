PHP

The right PHP for each project

Every project picks its own version and gets its own PHP-FPM pool. Laravel projects use the version their composer.json asks for.

  • Xdebug only where you need itSwitch it on for one project; your php.ini stays as it is.
  • Apache or NginxApache reads .htaccess. Nginx falls back to index.php for pretty URLs.
  • Behaves like MAMPUpload size, memory and buffering defaults match, so moved sites work the same.

FAQ

Questions, answered

Which PHP versions can I use?

Any version Homebrew installs, side by side: PHP 7.1 to 8.5, and older versions through the shivammathur tap. Each project picks its own.

Do I need Laravel Valet?

No. If Valet is installed, LocalSites uses its domains and certificates and leaves your Valet sites alone. Without Valet it runs its own HTTPS proxy and DNS for .test.

Can it run things that aren’t PHP?

Yes. Next.js and Node dev servers are detected, and any command or Docker Compose setup can run behind https://name.test.
